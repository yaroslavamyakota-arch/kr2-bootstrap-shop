# Контрольная работа №3

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание проекта
Проект представляет собой многостраничный сайт студии йоги "Баланс", разработанный с использованием CSS-фреймворка Bootstrap 5. 
Пользователи могут ознакомиться с направлениями, изучить профили тренеров, посмотреть расписание, почитать полезные статьи, узнать цены на абонементы и записаться на пробное занятие через интерактивные формы.

## Ссылка на опубликованный проект
GitHub Pages: `https://yaroslavamyakota-arch.github.io/kr2-bootstrap-shop/`

## Реализованные страницы
- `index.html` — Главная страница (hero-блок, преимущества, чек-лист для новичков с квизом, популярные направления, филиалы, отзывы).
- `catalog.html` — Каталог направлений с рабочими фильтрами по уровню сложности, а также блок с абонементами (перенесен сюда).
- `product.html` — Динамическая страница направления (подтягивает данные в зависимости от выбранной карточки, включает таблицу расписания и аккордеон FAQ).
- `schedule.html` — Общее расписание занятий с фильтрацией по филиалам и вкладками по дням недели.
- `trainers.html` — Страница тренеров с выезжающими панелями (Offcanvas) и кратким описанием достижений.
- `materials.html` — Журнал студии (полезные статьи в модальных окнах и словарь терминов в аккордеоне).
- `about.html` — Страница "О нас" с контактами филиалов и Яндекс.Картой.
- `order.html` — Страница записи с формой и кастомной валидацией.

## Используемые технологии
- **HTML5** (семантическая разметка)
- **Bootstrap 5** (сетка, компоненты, утилиты)
- **Bootstrap Icons** (векторные иконки)
- **JavaScript** (ES6)
- **CSS3** (кастомные стили, переменные)

## Реализованные компоненты Bootstrap
В проекте использованы следующие компоненты:
- `navbar` — навигационная панель (адаптивная, с телефоном и часами работы);
- `card` — карточки товаров, тренеров, статей и отзывов;
- `btn` — кнопки (основные и второстепенные);
- `badge` — значки (метки уровней сложности);
- `modal` — модальные окна для быстрой записи и чтения статей;
- `offcanvas` — выезжающие панели с информацией о тренерах;
- `accordion` — блоки с частыми вопросами (FAQ) и словарем терминов;
- `alert` — информационные сообщения;
- `carousel` — слайдер с фотографиями в блоке для новичков на главной странице;
- `nav-pills` — вкладки для переключения дней недели в расписании;
- `toast` — всплывающие уведомления об успешной отправке формы;
- формы (`form-control`, `form-select`, `form-check`, `input-group`);
- адаптивная сетка (`container`, `row`, `col-*`).

## Самостоятельные доработки (сверх базы)
- **Динамическая страница `product.html`**: вместо создания 5 отдельных файлов используется один, который читает URL-параметр (например, `?direction=vinyasa`) и автоматически подставляет нужный текст, картинку, цену, тренеров и расписание.
- **Страница общего расписания (`schedule.html`)**: создана сложная интерактивная таблица с вкладками по дням недели и кастомным JavaScript-фильтром по филиалам (Центральный, Южный, Северный).
- **Автозаполнение формы**: при клике на кнопку «Записаться» в расписании или на странице направления, форма в `order.html` автоматически подставляет выбранное направление, тренера и филиал (через передачу URL-параметров).
- **Блок «Первый раз в студии?»**: реализован интерактивный квиз для подбора направления и карусель с фотографиями.
- **Журнал студии (`materials.html`)**: создан раздел с 6 статьями (открываются в красивых модальных окнах) и словарем йогических терминов.
- **Чат-виджет консультанта**: в левом нижнем углу добавлен плавающий виджет, который при клике открывает всплывающее окно с быстрыми ссылками на WhatsApp, Telegram и звонок.
- **Кастомные уведомления (Тосты)**: стандартные окна браузера `alert()` заменены на стильные всплывающие уведомления в правом верхнем углу (Bootstrap `toast`).
- **Рабочие фильтры в каталоге**: реализована фильтрация карточек по уровню сложности на JavaScript.
- **Интеграция Яндекс.Карт**: на странице "О нас" размещена интерактивная карта с филиалами.
- **Кастомная валидация и защита ввода**: в формы добавлена защита от ввода букв в поле телефона и проверка длины имени.
- **Кнопка «Наверх»**: фиксированная кнопка для быстрого возврата к началу страницы.
- **Кастомный дизайн**: переопределены стандартные цвета Bootstrap через CSS-переменные (`:root`), убраны стандартные синие обводки, добавлены мягкие тени, скругления и эффекты при наведении на карточки.

## Как проверить проект
1. Открыть главную страницу `index.html` (обратить внимание на блок с квизом и каруселью).
2. Проверить навигацию между всеми страницами.
3. В каталоге (`catalog.html`) попробовать выбрать фильтры.
4. Перейти в общее расписание (`schedule.html`), переключить дни недели и попробовать фильтр по филиалам.
5. Нажать «Записаться» в расписании — форма в `order.html` должна заполниться автоматически.
6. На странице тренеров (`trainers.html`) нажать на карточку тренера.
7. Открыть «Полезные материалы» (`materials.html`) и почитать статьи в модальных окнах.
8. Нажать на зеленую иконку чата в левом нижнем углу.
9. Отправить любую форму и увидеть красивое всплывающее уведомление (тост) вместо стандартного `alert()`.
