# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание проекта
Проект представляет собой многостраничный сайт студии йоги "Баланс", разработанный с использованием CSS-фреймворка Bootstrap 5. 
Пользователи могут ознакомиться с направлениями, изучить профили тренеров, узнать цены на абонементы (на странице направлений) и записаться на пробное занятие через интерактивные формы.

## Ссылка на опубликованный проект
GitHub Pages: `https://yaroslavamyakota-arch.github.io/kr2-bootstrap-shop/`

## Реализованные страницы
- `index.html` — Главная страница (hero-блок со слоганом, преимущества, популярные направления, филиалы, отзывы).
- `catalog.html` — Каталог направлений с рабочими фильтрами по уровню сложности, а также блок с абонементами (перенесен сюда).
- `product.html` — Динамическая страница направления (подтягивает данные в зависимости от выбранной карточки).
- `trainers.html` — Страница тренеров с выезжающими панелями (Offcanvas) и кратким описанием достижений.
- `about.html` — Страница "О нас" с контактами филиалов и Яндекс.Картой.
- `order.html` — Страница записи с формой и кастомной валидацией.

## Используемые технологии
- **HTML5** (семантическая разметка)
- **Bootstrap 5** (сетка, компоненты, утилиты)
- **Bootstrap Icons** (векторные иконки)
- **JavaScript** (ES6)
- **CSS3** (кастомные стили, переменные)

## Реализованные компоненты Bootstrap
В проекте использованы следующие компоненты:
- `navbar` — навигационная панель (адаптивная, с телефоном и часами работы);
- `card` — карточки товаров, тренеров и отзывов;
- `btn` — кнопки (основные и второстепенные);
- `badge` — значки (метки уровней сложности);
- `modal` — модальное окно для быстрой записи;
- `offcanvas` — выезжающие панели с информацией о тренерах;
- `accordion` — блок с частыми вопросами (FAQ);
- `alert` — информационные сообщения;
- формы (`form-control`, `form-select`, `form-check`, `input-group`);
- адаптивная сетка (`container`, `row`, `col-*`).

## Самостоятельные доработки (сверх базы)
- **Динамическая страница `product.html`**: вместо создания 5 отдельных файлов используется один, который читает URL-параметр (например, `?direction=vinyasa`) и автоматически подставляет нужный текст, картинку, цену, тренеров и расписание.
- **Рабочие фильтры в каталоге**: реализована фильтрация карточек по уровню сложности на JavaScript.
- **Интеграция Яндекс.Карт**: на странице "О нас" размещена интерактивная карта с филиалами.
- **Кастомная валидация и защита ввода**: в формы добавлена защита от ввода букв в поле телефона и проверка длины имени.
- **Кнопка «Наверх»**: фиксированная кнопка для быстрого возврата к началу страницы.
- **Кастомный дизайн**: переопределены стандартные цвета Bootstrap через CSS-переменные (`:root`), добавлены мягкие тени, скругления и эффекты при наведении на карточки.
- **Улучшенная типографика и UI**: кастомная шапка (с временем работы и единым размером шрифта), компактный футер с переработанной сеткой.
- **Перенос абонементов**: блок с ценами (`pricing.html`) был упразднен, а его содержимое интегрировано в `catalog.html` с якорем `#pricing` для удобства пользователей.

## Как проверить проект
1. Открыть главную страницу `index.html`.
2. Проверить навигацию между всеми страницами.
3. В каталоге (`catalog.html`) попробовать выбрать фильтры (Для новичков / Продвинутый).
4. Прокрутить каталог вниз, чтобы увидеть перенесенный блок с абонементами.
5. Нажать кнопку «Подробнее» на любой карточке, чтобы увидеть динамическую смену контента на странице `product.html`.
6. На странице тренеров (`trainers.html`) нажать на карточку тренера (появится боковая панель с подробным описанием).
7. Открыть модальное окно записи и попробовать отправить пустую форму (сработает валидация).
8. Проверить страницу «О нас» с картой и контактами.
