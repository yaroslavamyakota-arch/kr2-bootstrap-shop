# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
Проект представляет собой сайт студии йоги, разработанный с использованием CSS-фреймворка Bootstrap. Пользователи могут изучить направления, посмотреть тренеров, выбрать абонемент и записаться на занятие.

## Практическая работа 9
Выполнена главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация (`navbar`);
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных направлений (`row`, `col-*`);
- подвал страницы.

## Используемые технологии
- HTML
- Bootstrap 5
- CSS
- Git
